# Rootloop

A farming automation game you play by writing Python. One self-contained HTML file —
open `index.html` in any browser, phone included. Progress and code save to the device.

- **Original Python interpreter** in JS: lexer, parser and a generator-based evaluator that
  pauses on every drone action so farm time can pass. Supports functions, closures, lambdas,
  comprehensions, f-strings, `try/except`, lists/tuples/dicts/sets and their common methods.
- **The farm**: grass, bushes, tilling, irrigation, carrots, merging pumpkins, sunflower petal
  puzzles, cactus sorting via `swap()`, dinosaur feeding, a hedge maze, and a fluctuating market.
- **Mobile-first UI**: canvas field view, syntax-highlighted editor with a snippet key bar,
  shop, log and a full command guide.

No build step and no dependencies. Everything runs client-side.
